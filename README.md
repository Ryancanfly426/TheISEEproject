# ISEE Grade 8 Word Sprint

單頁式 ISEE Grade 8 字彙訓練網站，按「申請 Grade 8」設計，對應 Middle Level。ERB 的級別說明以申請年級為準；若考生目前已讀 Grade 8 並申請 Grade 9，應確認是否需要 Upper Level。

## GitHub Pages 發佈

1. 在 GitHub 建立一個新的 repository。
2. 將 `index.html` 上傳到 repository 根目錄。
3. 到 **Settings → Pages**，選擇 **Deploy from a branch**，來源選 `main` 與 `/ (root)`，然後儲存。
4. 等待 Pages 完成部署後，GitHub 會顯示網站網址。

學習進度僅存於使用者瀏覽器的 localStorage，不會傳到 GitHub。
